Python · Machine Learning · SHAP · Healthcare

Diabetes Readmission Risk Predictor

MSc distinction-level research project predicting 30-day hospital readmission risk among diabetic patients using structured EHR data from 100,000+ patient records across 130 US hospitals. Deployed as a live interactive web application with SHAP explainability.

Key Results
XGBoost achieved best balance — 71% accuracy, 0.50 recall, AUC 0.64
5 models compared — XGBoost, CatBoost, Random Forest, DNN, Decision Tree
SHAP analysis identified discharge disposition and diagnosis count as top predictors
Deployed live on Hugging Face with real-time SHAP explanations per patient
